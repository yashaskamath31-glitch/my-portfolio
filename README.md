## 🌟 Highlights & Features

- **Dark Luxury UI/UX**: Designed with a deep slate background, cyan/indigo ambient radial glow, and backdrop-blur glassmorphic surfaces.
- **Interactive Python Code Sandbox**: An in-browser terminal code inspector showcasing profile attributes with simulated real-time code execution.
- **Flagship Project — AI Job Match & Resume Analyzer**:
  - Full architectural pipeline documentation (Ingestion, NLP Extraction, Scoring Engine, Gap Analysis).
  - Built-in **Interactive Live Simulator** allowing visitors to evaluate sample job roles (AI/ML Developer, Python Trainee, Data Analyst) against candidate qualifications.
- **Education Timeline**: Visual chronological milestones highlighting B.E. (CGPA 7.8), PUC (84%), and 10th Standard Distinction (88%).
- **Multilingual Showcase**: Native badges and proficiency levels across 5 languages: Kannada, English, Hindi, Marathi, and Malayalam.
- **Real Working Contact Hub**: Direct mail client composer (`mailto:` launcher), 1-click email copy with animated feedback, and verified LinkedIn profile card.

## 🚀 Getting Started Locally

### 1. Prerequisites
Ensure you have [Node.js](https://nodejs.org/) (v18+) installed.

### 2. Installation
Clone the repository and install the dependencies:

```bash
git clone https://github.com/yashaskamath31-glitch/my-portfolio.git
cd my-portfolio
npm install
```

### 3. Development Server
Start the local Vite development server with Hot Module Replacement (HMR):

```bash
npm run dev
```

### 4. Build for Production
To generate an optimized production bundle:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
